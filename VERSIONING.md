# Versioning

Registry versions apply to the governed registry and its source schema.

- **PATCH**: wording fixes, accession backfills, metadata improvements, or non-semantic generation changes
- **MINOR**: backward-compatible additions, new variables, new template families, or new pattern combinations
- **MAJOR**: breaking changes such as renamed canonical IDs, changed semantics, changed units, or changed expansion rules

Concrete public `variableId` values should be treated as stable once released publicly.
